# Santanu Biswas Portfolio Website

This is a personal portfolio website for Santanu Biswas, showcasing education, skills, projects, certifications, and leadership roles. The website is built using only **HTML** and **CSS** for a clean, responsive, and modern design.

## Features

- Responsive layout suitable for desktops and mobile devices
- Clear sections including Objective, Education, Skills, Projects, Certifications, and Leadership
- Visual progress bars to represent academic scores
- Stylish navigation bar with hover effects and smooth scrolling
- Downloadable Resume link for easy access
- Links to professional profiles and certificates
- Modern fonts and subtle color gradients for an appealing visual experience

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Montserrat and Roboto)

## How to Use

1. Clone or download this repository.
2. Customize the `index.html` to update personal information, projects, and skills.
3. Replace the profile image `profile.jpg` with your own photo or remove the image tag if not needed.
4. Update resume and certificate download/view links as desired.
5. Open `index.html` in any modern browser to view the portfolio locally.
6. (Optional) Host the portfolio online using platforms like GitHub Pages, Netlify, or Vercel for free.

## Hosting with GitHub Pages

- Create a GitHub repository.
- Upload your portfolio files (`index.html`, `style.css`, images).
- Enable GitHub Pages from the repository settings.
- Access your site via the provided GitHub Pages URL.
